Getting started

Install, run, and check that it works.

nCAS is five independent programs, each a single Python file in a TI-Nspire document. Install the ones you want; none of them needs the others.

ProgramWhat it isSizeNeeds
ncasguiThe full-screen CAS: 2D entry with templates, menus, catalog, results drawn as math.274 KB · 14 partsOS with ti_draw and get_key
ncastextThe same CAS at a > prompt in the Python Shell, with numbered menus.240 KB · 12 partsany OS with Python
ncasxA small, fast exact calculator: exact value plus decimal, no menus.59 KB · 3 partsany OS with Python
navcalcAviation (E6B) calculator: wind, crosswind, time-speed-distance, fuel, altitudes, airspeed.21 KB · 2 partsti_draw (else Shell)
unitconvUnit converter: 16 categories, about 150 units, all converting as you type.15 KB · 1 partti_draw (else Shell)
step 1

Download

Get the .tns documents from the latest release.

step 2

Send to the handheld

Connect by USB and drag the document onto the calculator in the TI-Nspire software (My Documents).

step 3

Run

Open the document and press ctrl R. On a CX II the CAS starts full screen; Press-to-Test must be off.

Or build a document yourself

The TI editor refuses very large pastes, so a helper puts a program on the clipboard one part at a time. Make a new Python program with the name shown, paste each part at the end, then Check Syntax & Save.

python3 tools/paste_parts.py onefile/ncasgui.py 20000

Use ncastext.py, ncasx.py, navcalc.py or unitconv.py for the others. The helper prints how many lines the program should have after each part.

Saved between runs

Settings, variables and functions are kept in the document (list ncasmem), so they are still there after a restart. Save the document to keep them after closing it.

Exams

Press-to-Test hides every file, nCAS included. Check what your exam allows.

ncasgui

The full-screen mode.

Modelled on the CAS Calculator app: type on the entry line at the bottom, press enter, and the input (left) and result (right) go into the history, drawn in 2D. The status bar shows the angle unit, the mode and real/complex, or the syntax of the command you are typing.

ncasgui · 2D entry

Fractions, powers, roots and calculus, as templates.

The entry line is 2D: templates have slots you type into. ◄ ► move through the slots, ▲ ▼ move between numerator and denominator or between the limits, and tab jumps to the next empty field.

ncastext

The command line in the Python Shell.

Type a command at the > prompt and press enter. m opens numbered menus that build the command for you, ? shows help, q quits. The prompt shows settings that differ from the defaults, such as deg>.

Menu mode

At the prompt type m. Pick items by number or letter and answer the questions; enter accepts the default in brackets, 0 goes back and q leaves. nCAS shows the command it built and runs it.

-- nCAS menu -- 1 Algebra 2 Calculus 3 Solve 4 Matrix 5 Number/cplx 6 Lists/stats 7 Convert 8 Settings #: 2 -- Calculus -- 1 Derivative 2 Deriv at pt 3 Integral 4 Def integral ... #: 4 f: e^(-x) Var [x]: Lower (inf ok): 0 Upper: inf > integral(e^(-x),x,0,inf) 1

Matrices can be typed as 1,2;3,4 in the menus. From the Shell, cas() restarts the text mode and gui() opens the full-screen mode.

ncasx

A small exact calculator.

Type an expression and get the exact value, with its decimal when they differ. No menus and no modes; it loads three times faster than the full CAS. q quits.

navcalc

Aviation calculator (E6B).

Pick a tool. Each tool is a form: type the values you know and leave the others blank; the blank fields (?) are solved as you type, in blue. Any field can be the blank one. A value can be a sum such as 120+15, and ◄ ► change a field’s unit.

Keys: ▲ ▼ tab enter move between fields, ◄ ► change the unit, del deletes, clear blanks a field, (−) changes the sign, esc/menu back to the list. The status bar says what is missing (“enter 1 more value”, “too many values: clear 1”, “no solution”). ICAO standard atmosphere; for planning and training, not a certified instrument.

unitconv

Unit converter.

Pick a category: every unit in it is listed. Type a value in any row and all the other rows convert as you type. The typed row is black with the cursor; converted values are blue; the status bar shows the selected row to 12 digits.

Keys: ▲ ▼ tab enter move, ◄ ► page up/down, del deletes, clear empties the row, EE exponent (1.5E6), ? help, esc/menu back to the categories. Factors are the exact definitions.

Troubleshooting

When something does not work.

Most problems on a real calculator come from key names, memory, or a paste that went wrong.

“key … not used”

The status bar names a key nCAS does not use. Open the key test, note the name, and report it on GitHub.

Out of memory

nCAS shortens the history and keeps going; your variables stay. :free clears history, undo and ans. Very large requests stop at once with “Resource limit”.

The program does not start

Turn Press-to-Test off. If the full-screen mode cannot read keys on an older OS, ncasgui opens a compact screen mode in the Shell instead (type, m for menus, q quits).

Syntax error after pasting

A part was pasted twice or missed. Compare the line count with what paste_parts.py printed, or start a new program and paste again.

A long calculation

Exact big-integer work cannot be interrupted on the calculator, so nCAS refuses huge powers and factorials up front instead of freezing.

Report a problem

Open an issue on GitHub with the input, what you saw, and a photo if the screen looks wrong.
