For the TI-Nspire CX II · non-CAS

The CAS your calculator didn’t ship with.

nCAS adds exact arithmetic, solving, calculus, symbolic matrices and differential equations to the plain CX II, written entirely in its built-in Python. Commands follow the TI-Nspire CAS Reference Guide, so solve(x^2-5x+6=0,x) works exactly as on a CAS model.

Calculus templates

Write integrals and derivatives with ∫ and d/dx.

The full-screen mode has the same calculus templates as the CAS: an integral sign with optional limits, and the derivative fraction d/dx. You fill the slots on the entry line, see the expression drawn in 2D, and get an exact answer. Each picture below is a real nCAS screen, with the keys that produced it.

Open a template: menu ▸ 9 Templates, then a for ∫, b for ∫ with limits, c for d/dx. The variable slot starts as x.

Move between slots: ▲ goes to the upper limit and ▼ to the lower one; ► and tab step through the integrand and the variable.

Without templates: type integral(f,x,a,b), ∫(f,x) or d(f,x). The history still draws them with ∫ and d/dx.

Three programs

Pick the one that fits the moment.

Each is a single Python file you paste into a TI-Nspire document. Install one or all three; they don’t depend on each other.

ncasgui

Full screen, modelled on the CAS Calculator app. 2D entry with ∫, d/dx, fraction, root and matrix templates, results drawn as real math, menus and a catalog that shows each command’s syntax.

Install

Three steps, about two minutes.

You need the TI-Nspire computer software (Student or Teacher) and a CX II with OS 5.2 or later, in normal mode.

step 1

Download

Get the ready-made .tns document from the latest GitHub release.

step 2

Send it to the handheld

Connect the calculator by USB and drag the document onto it in the TI-Nspire software. Keep it in My Documents.

step 3

Run it

Open the document and press ctrl R. Type :test once: you should see 18/18 tests passed.

Build the document yourself

The TI editor refuses a paste this large, so the repository includes a helper that puts the program on the clipboard one part at a time. Paste each part at the end of a blank Python program, then use Check Syntax & Save.

python3 tools/paste_parts.py onefile/ncasgui.py 20000
Kept between runs

Settings, variables and functions are saved inside the document, so f(x):=x^2+1 is still there after you restart the program or reopen the file.

Exams

Press-to-Test hides nCAS along with every other file, and many exams don’t allow CAS functions. Check your exam’s rules.
